Developers & Integrations

api KV Download REST & Aria2 JSON-RPC API

Connect third-party browser extensions, Python scripts, cURL, home automation, and Ghost Downloader directly to KV Download.

Aria2 JSON-RPC 2.0 Server

POST /jsonrpc • POST /rpc

Port 9292 • Active

KV Download implements full compatibility with Aria2 protocol specifications. Any browser extension or tool that exports to Aria2 (e.g., Aria2 Download Manager, Camellia, YAAW, Ghost Downloader, Baidu exporter) will work out of the box.

curl -X POST http://localhost:9292/jsonrpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":"1","method":"aria2.addUri","params":[["https://www.youtube.com/watch?v=..."]] }'

REST API Reference

POST /api/queue/add
Enqueue download tasks 
curl -X POST http://localhost:9292/api/queue/add \
  -H "Content-Type: application/json" \
  -d '{ "urls": ["https://www.tiktok.com/@user/video/..."], "format": "best", "rateLimit": "5M" }'
GET /api/scan?url={URL}
Extract tracks, playlists & M3U8 streams 
curl "http://localhost:9292/api/scan?url=https://www.youtube.com/playlist?list=..."
GET /api/queue
List all active, pending, and completed tasks 
curl http://localhost:9292/api/queue
GET /api/events
Real-time SSE progress stream 
const es = new EventSource('/api/events');
es.onmessage = (e) => console.log(JSON.parse(e.data));

Device Storage Only: Cookies are stored locally in your browser and sent ephemerally only when downloading — never stored on disk on the server.

How to export cookies on your device:
1
Install Cookie Extension Install Cookie-Editor or Get cookies.txt LOCALLY in Chrome, Edge, Brave, or Firefox.
2
Export from Target Site Navigate to TikTok, YouTube, Instagram, or Threads and log in. Click Cookie-Editor → Export → Export as JSON.
3
Paste & Save Click Paste above, then click Save to This Device. Cookies are stored locally on your device.
Safari Bookmarklet (Recommended)

Create a bookmark in Safari, edit its URL, and paste this code:

javascript:(function(){var c=document.cookie;if(!c){alert('No cookies found on this page. Make sure you are logged in.');}else{prompt('Copy your cookies below:',c);};return false;})(); When on TikTok/YouTube/Instagram in Safari, tap bookmarks → tap the Bookmarklet → copy prompt text → paste here.
Raw Header String

You can also paste raw session strings directly (e.g. sessionid=xxxx; sid_guard=yyyy;).

Kiwi Browser / Firefox Nightly

Install Kiwi Browser or Firefox Android (both support extensions). Add Cookie-Editor → open site → click Export JSON → paste here.

Chrome Remote Debugging

Connect phone to computer via USB → open chrome://inspect → run copy(document.cookie).
